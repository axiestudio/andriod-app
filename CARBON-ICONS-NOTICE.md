# Carbon icons attribution

The six glyphs in `app/src/main/res/drawable/ic_carbon_*.xml`
(`play`, `stop`, `settings`, `touch--1`, `arrow--left`, `home`) are converted
from the [IBM Carbon icon set](https://carbondesignsystem.com/elements/icons/library/),
package `@carbon/icons` **v11.87.0** — the same icon library the CRM web app
(`apps/web`, `@carbon/icons-react`) uses.

Carbon icons are © IBM Corp. and licensed under the
[Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0).
Only path data was reused (re-expressed as Android VectorDrawables, black fill,
tinted at usage); no IBM trademarks are claimed.

Full license text ships with the source package (`@carbon/icons/LICENSE`).
